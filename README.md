## Java Chatbox Application
# Description
This is a simple Chatbox Application built using Java. The application allows real-time communication between clients over a local server (localhost: 127.0.0.1). It includes both a Graphical User Interface (GUI) for ease of use and a console-based chat for simpler interaction.
# Features
Client-Server Architecture:<br />
The application uses a local server (127.0.0.1) to handle communication between multiple clients.<br />
Graphical User Interface (GUI):<br />
A user-friendly interface to send and receive messages.<br />
Real-Time Communication:<br />
Messages are sent and received instantly.<br />
Cross-Platform:<br />
Runs on any system with a Java Runtime Environment (JRE).<br />
